# Tractor — испытания электротрактора JINMA YL254ET и сравнение с дизельным аналогом

Научно-исследовательская работа: полевые испытания электротрактора JINMA YL254ET (тяговый класс 0,6)
с навесным культиватором и культиваторной фрезой (почва: твёрдость 15 кгс/см² = 1,47 МПа, влажность 10 %),
методика сравнения с дизельным трактором того же класса (JINMA JM-254) и зоны оптимального использования.

## Методические решения

- Буксование определяется по ГОСТ 7057: δ = 1 − N₀/N, где N и N₀ — число оборотов вала двигателя хода на
  учётной делянке при рабочем и холостом проходах на одной передаче (теоретическая скорость не используется).
- Допустимое буксование 16 % — значение, при котором ГОСТ 27021-86 определяет номинальное тяговое усилие 4К4.
- Показатели дизельного аналога рассчитываются по измеренному тяговому сопротивлению орудия, опытной кривой
  буксования δ(φ) и модели расхода топлива ASABE D497.7 (поправочный коэффициент k_Д = 0,85–1,20).
- Единичные показатели приводятся к шкале [−1; 1] нормированной разностью; комплексный показатель — взвешенная
  сумма. Веса групп — метод анализа иерархий; внутри группы вес распределяется по среднему локальных весов МАИ и
  энтропийных. Устойчивость вывода — вероятность P(I > 0) по методу Монте-Карло (1000 реализаций).
- Модель смены ограничена сменным заданием: работа прекращается по его выполнении; организационная зона —
  область, где электротрактор выполняет задание и I > 0.
- Точность модели агрегатов проверена перекрёстной проверкой с исключением режима; расширенная неопределённость —
  по ГОСТ 34100.3 с коэффициентом охвата по эффективному числу степеней свободы (формула Уэлча – Саттертуэйта).

## Воспроизведение

```bash
pip install pandas numpy scipy statsmodels python-docx openpyxl pillow
# для PDF и проверки Excel нужны LibreOffice (с модулем Math), pandoc, poppler-utils
python3 src/process.py        # показатели проходов, баланс энергии
python3 src/analysis.py       # статистика, модели, сравнение, Монте-Карло, зоны
python3 src/export_matlab.py  # данные для рисунков (matlab/data/*.csv)
cd matlab && matlab -batch make_all && cd ..   # рисунки; без MATLAB: octave --no-gui --eval make_all
python3 src/build_excel.py    # рабочая книга Excel
python3 src/build_report.py   # отчёт и ПМИ (DOCX + PDF)
```

Исходные данные и допущения собраны в `src/params.py` (у каждого значения указан статус: опыт,
паспорт, внешний источник или допущение с диапазоном вариации).
